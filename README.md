# The Juniper Table — Restaurant Ordering Demo

A responsive fictional restaurant website created as a QORVI Studio portfolio demonstration.

## Features
- Responsive landing page and restaurant story
- Searchable menu with category filters
- Add-to-bag interactions and quantity controls
- Cart subtotal calculation
- Checkout form with delivery/pickup selection
- Simulated order confirmation with demo order number
- No payment processing and no live order transmission

## Run locally
Open `index.html` in a modern browser. In VS Code, use Live Server or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before using for a real client
Replace fictional business details, prices, images, location, hours and contact information. Connect the order form to a secure backend and a payment provider before accepting real orders. Do not collect real customer information with this static demo.

## Notes
- Food photos are loaded from Unsplash URLs and require an internet connection.
- Currency is displayed in Nigerian naira.
- This is a front-end demonstration, not a production ordering system.
